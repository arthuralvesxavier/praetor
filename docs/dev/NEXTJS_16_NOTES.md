# Next.js 16.4 notes for this project

Our training data may predate Next 16. Bundled docs: `node_modules/next/dist/docs/`.

## Rendering model

- `cacheComponents` is **disabled** in `next.config.ts` (ADR-0002). Reading `cookies()`
  makes a route dynamic; no Suspense requirement, no `'use cache'`.
- Do NOT export `dynamic`/`revalidate` segment configs unless necessary.
- Layouts don't re-render on navigation: always authorize in the page / action / route handler,
  never only in a layout.

## Request APIs

- `cookies()`, `headers()`, `params`, `searchParams` are **Promises**. Await them.
- Global type helpers (no import): `PageProps<'/processos/[id]'>`, `LayoutProps<'/'>`,
  `RouteContext<'/api/x/[id]'>`. They are generated by `next dev`/`next build`/`next typegen`
  (`npm run typecheck` runs `next typegen` first).
  ```tsx
  export default async function Page(props: PageProps<"/processos/[id]">) {
    const { id } = await props.params;
    const sp = await props.searchParams; // Record<string, string | string[] | undefined>
  }
  ```

## Proxy (formerly middleware)

- File `src/proxy.ts`, export `function proxy(request)`. Node runtime. Optimistic checks only.
- Upload route `/api/documents/upload` is excluded from the matcher (proxy would buffer bodies).

## Server Actions

- `"use server"` at top of `actions.ts`. `useActionState` from `"react"`; `useFormStatus` from `"react-dom"`.
- Action signature with useActionState: `(prevState, formData: FormData)`.
- `revalidatePath(path)` from `next/cache`; `redirect()` from `next/navigation` (throws — call outside try/catch).
- `revalidateTag(tag, "max")` requires 2 args in v16. Prefer `revalidatePath`.
- Body limit configured at `experimental.serverActions.bodySizeLimit` (2mb). File uploads go through
  the route handler `/api/documents/upload`, not server actions.

## Route handlers

```ts
export async function GET(request: NextRequest, ctx: RouteContext<"/api/documents/[id]/versions/[versionId]/download">) {
  const { id, versionId } = await ctx.params;
}
```
Upload: `const form = await request.formData(); const file = form.get("file") as File`.
Download: `return new Response(stream, { headers: { "Content-Type": ..., "Content-Disposition": ... } })`.

## Special files

- `error.tsx` must be `"use client"`; props `{ error, reset }` (16.3 also provides `retry`).
- `loading.tsx`, `not-found.tsx` as usual. `forbidden()`/`unauthorized()` are experimental — not used;
  we redirect to `/sem-permissao` instead.

## Tooling

- `next lint` was removed: use `npm run lint` (eslint flat config).
- Turbopack is the default bundler for dev and build.
- `next build` type-checks.
